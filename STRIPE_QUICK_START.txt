📋 MANUAL SETUP STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Create Stripe Account
─────────────────────────────
1. Go to: https://dashboard.stripe.com/register
2. Sign up with your email
3. Verify your email

STEP 2: Get API Keys
───────────────────
1. Log in to: https://dashboard.stripe.com
2. Click "Developers" (top right)
3. Click "API keys"
4. Under "Standard keys" you'll see:
   - Publishable key (starts with pk_test_)
   - Secret key (starts with sk_test_)
5. COPY THE SECRET KEY (this is your API key)

STEP 3: Get Webhook Secret
──────────────────────────
1. Still in Developers section
2. Scroll to "Webhooks"
3. Click "Add an endpoint"
4. Enter: http://localhost:8080/api/v1/webhooks/stripe
5. Select these events:
   - charge.succeeded
   - charge.failed
   - payment_intent.succeeded
   - payment_intent.payment_failed
6. Click "Create endpoint"
7. Click "Reveal" to show Webhook Signing Secret (starts with whsec_)
8. COPY THIS SECRET

STEP 4: Set Environment Variables
──────────────────────────────────
Create/edit ~/.zshrc_pgconnect_stripe with:

```
export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"
export PATH="/opt/homebrew/opt/postgresql@15/bin:$PATH"
export DB_URL='jdbc:postgresql://localhost:5432/pgconnect'
export DB_USERNAME='mkuma153'
export DB_PASSWORD=''
export STRIPE_API_KEY='sk_test_your_key_here'
export STRIPE_WEBHOOK_SECRET='whsec_your_secret_here'
```

STEP 5: Update Project Dependencies
────────────────────────────────────
Your pom.xml will need Stripe dependency. See: STRIPE_MIGRATION_GUIDE.md

🔗 API ENDPOINT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create Payment:
  POST http://localhost:8080/api/v1/customer/rent/payments
  
  Headers:
    Content-Type: application/json
    X-Authenticated-User: <user-uuid>
    Idempotency-Key: <unique-key>
  
  Body:
    {
      "invoiceId": "<invoice-uuid>",
      "amount": 2500.00,
      "customerPhone": "9876543210"
    }

Response:
    {
      "paymentOrderId": "<order-uuid>",
      "orderReference": "ORDER-123456",
      "amount": 2500.00,
      "status": "pending",
      "clientSecret": "pi_test_..._secret_..."
    }

The clientSecret is used by your frontend to complete the payment using Stripe.js

❓ FAQ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Do I need a bank account for Stripe testing?
A: No! Stripe sandbox (test mode) works with test cards only.

Q: How do I test locally without exposing my API key?
A: Use environment variables. Never hardcode keys in code.

Q: Can I test webhooks locally?
A: Yes! Use Stripe CLI: brew install stripe/stripe-cli/stripe
   Then: stripe listen --forward-to localhost:8080/api/v1/webhooks/stripe

Q: Do I need a website for Stripe?
A: No! Stripe works for backend APIs and mobile apps.

Q: Can I switch back to Cashfree later?
A: Yes! You can create a PaymentGateway interface and swap implementations.

Q: What about production?
A: Get live API keys from Stripe, follow PCI compliance,
   and implement proper security (HTTPS, authentication, rate limiting).
